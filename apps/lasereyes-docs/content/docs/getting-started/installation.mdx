---
title: Installation
description: Add LaserEyes to your project.
---

Install the core library and, for React apps, the React bindings:

```bash tab="npm"
npm install @omnisat/lasereyes-core @omnisat/lasereyes-react
```

```bash tab="pnpm"
pnpm add @omnisat/lasereyes-core @omnisat/lasereyes-react
```

```bash tab="yarn"
yarn add @omnisat/lasereyes-core @omnisat/lasereyes-react
```

```bash tab="bun"
bun add @omnisat/lasereyes-core @omnisat/lasereyes-react
```

## Peer dependencies

LaserEyes expects `react >= 17` and `nanostores >= 0.11` to be present in React
apps. Most bundlers will install these automatically.

Next, continue to the [Quick Start](/docs/getting-started/quick-start).
