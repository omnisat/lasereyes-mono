LaserEyes is a Bitcoin wallet connect library for building Bitcoin Ordinal web
apps. It provides a framework-agnostic core plus React bindings for integrating
Bitcoin wallets (Leather, OKX, Orange, OYL, Unisat, Wizz, Phantom, Xverse, and
more) into your dApp.

## Packages

- **`@omnisat/lasereyes-core`** — framework-agnostic wallet integration built on
  a config value + free-function actions, with reactive state via nanostores.
- **`@omnisat/lasereyes-react`** — React bindings: a provider and query-backed
  hooks (`useConnect`, `useAccount`, `useBalance`, …).
- **`@omnisat/lasereyes-client`** — composable Bitcoin data client (balances,
  UTXOs, fees, transactions, PSBT utilities) with pluggable backends.

## Get started

Head to [Installation](/docs/getting-started/installation) to add LaserEyes to
your project, then [Quick Start](/docs/getting-started/quick-start) to connect a
wallet in a few lines.
